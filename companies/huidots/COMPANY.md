# HuiDots

HuiDots is an Owner-overseen AI company. The Board Owner is the human overseer. Routine execution is AI.

## Hierarchy (Revision 2)

Owner → CEO
- COO (new)
- CTO → Web Engineer, App Engineer, UI/UX Designer, Engineering Reviewer
- CRO
- CMO → Production Director → Content Producer, Video Editor, Production QA
- CSO → Research Director (new), Business Analyst (new)
- CHRO (new)
- Utilities (paused): Summarizer, Reflection Coach

## Workflows

**Task flow:** Owner → CEO → Executive → Specialist → Executive consolidates → CEO decides → Owner (material decisions only).

**KIV/Opportunity flow (CSO):** CSO → Research Director → CSO evaluates → Business Analyst → CSO recommendation → CEO decision.

## Harness policy

- **MiniMax / pi_local (default):** executives, research/analysis, production, routine reviewer, monitoring, scraping, recurring ops. Video/motion uses Hailuo/MiniMax video.
- **Codex:** Web Engineer, App Engineer, code-heavy implementation.
- **Cursor (scarce):** UI/UX Designer, exceptional visual review, difficult independent review, high-value technical escalation. Never run CEO/CTO permanently on Cursor.
